Run a `/grilling` session, using the `/domain-modeling` skill.

**Scope constraint for this session:** The goal is to identify the next shippable slice, not the whole system. When the conversation starts expanding into a large or multi-phase design, surface the smallest version that still delivers value — "What is the minimum version of this that would be useful?" or "Could the rest wait?" Park deferred items explicitly rather than exploring them further.
