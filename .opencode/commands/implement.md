Use the `implement` skill.

Resolve the active story from both the product backlog tracker and handoff. Resume the exact cycle/phase when they agree; reconcile mismatches rather than guessing. Establish a scope baseline and intent packet, run one behavioural test per cycle, commit every verified green cycle, update relevant design/context records, validate the complete committed story range, triage findings by decision ownership, repair safe in-intent findings, run preflight, and update the tracker only when every gate passes.

Arguments: optional story file or story ID.
