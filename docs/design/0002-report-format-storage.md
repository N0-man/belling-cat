# Report Format and Storage

**Status:** Accepted
**Related PRD:** [belling-cat-mvp](../../.scratch/belling-cat-mvp/PRD.md)

## Decision

Save reports as Markdown files in `.reports/` directory with filename format: `belling-cat-{timestamp}.md`

## Why

PRD requires Markdown file generation that is human-readable and suitable for sharing or archiving (PRD Requirements 22-23).
