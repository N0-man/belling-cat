# Multi-Agent Architecture with LangGraph

**Status:** Accepted
**Related PRD:** [belling-cat-mvp](../../.scratch/belling-cat-mvp/PRD.md)

## Decision

Use LangGraph to orchestrate three specialized agents (Claim Decomposition, Investigation/Fact Finder, Verifier) for the MVP.

## Why

To experiment with parallel processing and state management capabilities. This choice will be revisited post-MVP based on learnings.
