## Implementation notes

### Evidence Association Approach

Current workflow state (Item 04):
```python
class InvestigationState(TypedDict):
    claim: str
    subclaims: list[SubClaim]
    evidence: list[Evidence]  # Flat list, no association
    verdicts: list[Verdict]
```

Target state (Item 04.1):
```python
class InvestigationState(TypedDict):
    claim: str
    subclaims: list[SubClaim]
    evidence: dict[str, list[Evidence]]  # Key = subclaim.text
    verdicts: list[Verdict]
    contradictions: list[str]
```

Investigation node change:
```python
# Before (Item 04):
for subclaim in subclaims:
    evidence = investigation_service.investigate(subclaim.text)
    all_evidence.extend(evidence)  # Loses association

# After (Item 04.1):
evidence_by_subclaim = {}
for subclaim in subclaims:
    evidence = investigation_service.investigate(subclaim.text)
    evidence_by_subclaim[subclaim.text] = evidence
```

Verification node change:
```python
# Before (Item 04):
for subclaim in subclaims:
    verdict = verifier_service.verify(subclaim, evidence_list)  # All evidence

# After (Item 04.1):
for subclaim in subclaims:
    relevant_evidence = evidence_by_subclaim.get(subclaim.text, [])
    verdict, contradictions = verifier_service.verify_with_contradictions(
        subclaim, relevant_evidence
    )
    verdicts.append(verdict)
    all_contradictions.extend(contradictions)
```

### CLI Integration Structure

```python
def investigate_handler(claim: str) -> str:
    # 1. Create workflow with all three services
    workflow = create_investigation_workflow(
        decomposition_service, investigation_service, verifier_service
    )
    
    # 2. Invoke workflow
    result = workflow.invoke({"claim": claim})
    
    # 3. Extract verdicts and contradictions
    verdicts = result.get("verdicts", [])
    contradictions = result.get("contradictions", [])
    
    # 4. Display to user
    display_verdicts(console, verdicts, contradictions)
    
    # 5. Prompt for approval
    approved = prompt_for_approval()
    
    # 6. Return appropriate message
    if approved:
        return "Investigation complete. Use /save to generate report."
    else:
        return "Investigation reviewed. Use /investigate to start a new investigation."
```
